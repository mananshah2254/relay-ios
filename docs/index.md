# Relay

Relay is an iPhone app for organizing job opportunities, preparing referral requests, and sending approved messages through a connected Gmail account. Version 1.2 introduces public setup with no invitation: tap Get started, then connect your own Gmail and contact-discovery account. Earlier builds may still show the invitation screen; update when the new version is available.
